# 1. 需求分析

## 1.1 项目背景

随着人们健康意识的不断提升，运动健身已成为日常生活的重要组成部分。然而，许多运动爱好者在记录运动数据、制定运动计划、追踪运动进度等方面**缺乏便捷的工具**。传统的运动记录方式（如纸质记录、通用备忘录）存在**数据易丢失、统计困难、无法直观展示运动趋势**等问题。

基于**HarmonyOS NEXT平台**的"运动健康助手"应用，旨在为用户提供一款**轻量级、智能化**的运动记录与管理工具。该应用充分利用HarmonyOS的原生能力，结合**AI语音交互技术**，让用户能够便捷地记录运动数据、查看运动统计、接收运动提醒，从而培养良好的运动习惯。

## 1.2 功能需求

本应用主要满足以下功能需求：

1. **运动记录管理**：支持添加、删除运动记录，记录包括运动类型、时长、消耗卡路里、运动日期等信息。
2. **周视图展示**：以周为单位展示运动记录，支持按周切换查看历史数据。
3. **今日运动追踪**：展示当日运动列表，支持选择运动项目并开始计时运动。
4. **运动计时器**：提供运动倒计时功能，实时显示剩余时间和已消耗卡路里。
5. **滑动手势操作**：支持左滑运动记录，快速完成或删除记录，提升交互效率。
6. **AI语音录入**：通过CoreSpeechKit语音识别引擎，用户可通过自然语言描述快速添加运动记录，支持中文数字识别（如"二十分钟"、"半小时"）。
7. **运动提醒通知**：支持发送运动提醒通知和运动完成通知，帮助用户养成规律运动习惯。
8. **个人数据统计**：统计总运动次数、总时长、总消耗卡路里，展示本周运动进度（目标150分钟/周）。
9. **数据持久化**：使用Preferences本地存储，确保数据在应用重启后不丢失。
10. **电源感知**：实时显示设备电量，帮助用户了解剩余续航。

# 2. 系统设计

## 2.1 功能模块划分

应用采用**模块化设计**，整体划分为以下功能模块：

### 2.1.1 运动记录模块（SportRecordPage）

周视图日历展示、运动记录添加/删除、日期选择器切换周。采用**Grid布局以7列等分**显示一周7天的运动记录，不同运动类型以彩色标签区分：跑步（橙红）、游泳（蓝）、户外散步（绿）、室内健身（紫）。已完成记录以半透明显示。

### 2.1.2 今日运动模块（TodaySportPage）

当日运动列表展示、运动项目多选、运动计时器（开始/暂停/结束）、**滑动手势操作**（左滑完成/删除）、AI语音添加运动、运动提醒通知、日期选择器切换查看历史记录、实时电池电量显示。

### 2.1.3 滑动操作组件（SwipeRecordItem）

基于**PanGesture手势识别**的滑动交互组件，支持用户在运动记录上左滑显示操作按钮（"已完成"/"删除"），松开后自动吸附定位，提升单手操作效率。已完成记录仅显示"删除"按钮，防止重复标记。

### 2.1.4 个人中心模块（ProfilePage）

用户概览卡片、运动数据统计三栏（总次数、总时长、总消耗）、本周运动进度条（目标150分钟/周）、周日期选择器切换统计周期、设置选项（通知设置、关于应用、清除运动数据含二次确认）。

### 2.1.5 数据管理模块（SportDataManager）

运动记录的增删改查、数据持久化存储、日期格式化工具。采用**单例模式**，通过Preferences的flush机制确保数据实时落盘。

### 2.1.6 AI语音模块

语音识别引擎全生命周期管理（初始化→监听→销毁）、语音内容语义解析（运动类型匹配、时长提取、卡路里提取）。包含**安全销毁机制（safeShutdown）**、**并发初始化防护（isInitLocked）**、**引擎状态追踪（isEngineReleased）**，以及录音超时（60秒）和无结果超时（10秒）检测。

## 2.2 数据库设计

## 2.3 AI语音交互设计

AI语音交互模块采用**"语音识别 + 自然语言解析"的两阶段架构**：

**1. 语音识别阶段**：通过CoreSpeechKit引擎将用户语音转换为文本，支持中文识别（zh-CN），最长录音时长60秒。引擎生命周期由SpeechRecognizerManager全权管理，包含安全销毁（safeShutdown）、并发初始化锁（isInitLocked）、引擎释放状态标记（isEngineReleased）等健壮性机制。

**2. 语义解析阶段**：通过SportVoiceParser解析识别文本，提取关键信息：

- **运动类型匹配**：支持跑步、游泳、骑行、健身、瑜伽、跳绳、走路、篮球、足球、羽毛球、爬山、乒乓球、网球、拳击、跳舞、滑雪、滑冰、举铁等**20+种运动类型**
- **时长提取**：支持阿拉伯数字（"10分钟"）、**中文数字**（"二十分钟"）、特殊表达（"半小时"="30分钟"、"一小时十五分钟"）等多种格式
- **卡路里提取**：支持"千卡"、"大卡"、"卡路里"、"卡"等多种单位表述

典型语音输入示例：

- "我刚跑步20分钟，消耗了150千卡"
- "游泳半小时，大概两百卡"
- "做了四十分钟室内健身"

```typescript
    // 解析并加载历史记录

    this.records.push(record);
    await this.save();
```

## 3.3 AI语音添加运动功能

### 3.3.1 语音识别管理器（SpeechRecognizerManager）

SpeechRecognizerManager是语音识别功能的核心模块，负责**CoreSpeechKit引擎的全生命周期管理**。与初版相比，当前版本引入了多项健壮性机制：

**① 安全销毁机制（safeShutdown）**：引擎释放前先校验isEngineReleased状态防止重复销毁，通过setTimeout异步执行shutdown避免阻塞UI主线程，销毁顺序严格遵循"先shutdown引擎→再置空监听器→再置空引擎引用"，从根本上**杜绝cb == nullptr空指针异常**。

```typescript
static async safeShutdown(): Promise<void> {
  if (SpeechRecognizerManager.isEngineReleased) return;
  SpeechRecognizerManager.isEngineReleased = true;
  const engineToShutdown =
    SpeechRecognizerManager.asrEngine;
  SpeechRecognizerManager.asrEngine = null;

  return new Promise<void>((resolve) => {
    setTimeout(async () => {
      try {
        if (engineToShutdown) {
          engineToShutdown.cancel(session);
          engineToShutdown.shutdown();
        }
      } catch (e) {/* 吞掉销毁异常 */}
      // 关键：引擎shutdown后再置空监听器
      SpeechRecognizerManager.recognitionListener = null;
      SpeechRecognizerManager.isListening = false;
      SpeechRecognizerManager.resultCallback = null;
      resolve();
    }, 0);
  });
}
```

**② 并发初始化锁（isInitLocked）**：防止用户在快速点击时触发多次init调用，通过isInitLocked标志位在初始化期间屏蔽重复请求，init完成后无论成功或失败均释放锁。

**③ 引擎状态追踪（isEngineReleased）**：独立追踪引擎释放状态，确保即便在异常路径（如onError回调）中也能正确追踪引擎生命周期。

**④ 多回调支持**：init方法接受三个回调参数——resultCallback（识别结果）、errorCallback（错误处理）、startCallback（麦克风就绪通知），startCallback在onStart事件中触发，用于UI层更新麦克风状态提示。

### 3.3.2 语音内容解析器（SportVoiceParser）

SportVoiceParser负责将语音识别文本解析为结构化的运动数据（运动类型、时长、卡路里）。核心特性：

**① 运动关键词匹配（20+种运动类型）**：通过SPORT_KEYWORDS映射表支持多种表达方式，如同义词归一化（"跑"/"跑步"→"跑步"、"打篮球"/"篮球"→"篮球"、"爬山"/"登山"→"爬山"、"举铁"/"力量训练"→"举铁"）。

**② 中文数字解析（chineseToNumber）**：支持"零"到"百"的中文数字转换为阿拉伯数字，并可处理复合表达式（如"二十"→20、"一百二十"→120）。

```typescript
const CN_NUM_MAP: Record<string, number> = {
  '零': 0, '一': 1, '二': 2, '三': 3,
  '四': 4, '五': 5, '六': 6, '七': 7,
  '八': 8, '九': 9, '十': 10, '百': 100
};

function chineseToNumber(cn: string): number {
  let result = 0, current = 0;
  for (const char of cn) {
    const val = CN_NUM_MAP[char] ?? -1;
    if (val < 0) continue;
    if (val >= 10) {
      if (current === 0) current = 1;
      result += current * val;
      current = 0;
    } else { current = val; }
  }
  return result + current;
}
```

**③ 时长提取（多格式兼容）**：支持"X小时Y分钟"阿拉伯数字格式、"X小时Y分钟"中文格式、"半小时"特殊表达（直接映射为30分钟）。

### 3.5.2 数据统计计算

```typescript
refreshProfileStats() {
  const mgr = SportDataManager.getInstance();
  const allRecords = mgr.getRecords();
  const completed = allRecords.filter(r => r.completed);

  // 总览统计
  this.profileTotalCount = completed.length;
  this.profileTotalDuration = completed.reduce(
    (s, r) => s + r.duration, 0);
  this.profileTotalCalories = completed.reduce(
    (s, r) => s + r.calories, 0);

  // 本周统计
  const now = new Date();
  const dow = now.getDay();
  const start = new Date(now);
  start.setDate(now.getDate() - dow +
    (dow === 0 ? -6 : 1));
  const days: Date[] = [];
  for (let i = 0; i < 7; i++) {
    const d = new Date(start);
    d.setDate(start.getDate() + i);
    days.push(d);
  }
  const weekRecords = mgr.getWeekRecords(days)
    .filter(r => r.completed);
  const daySet = new Set(
    weekRecords.map(r => r.sport_date));
  this.profileWeekDays = daySet.size;
  this.profileWeekDuration = weekRecords.reduce(
    (s, r) => s + r.duration, 0);
  this.profileWeekProgress = Math.min(100,
    Math.floor(this.profileWeekDuration * 100 / 150));
}
```

```typescript
// 10秒无结果超时检测
this.noResultTimeoutId = setTimeout(() => {
  if (this.isRecording && this.fullVoiceText.length === 0) {
    this.errorMessage = '未检测到语音输入，请检查麦克风是否正常或网络是否畅通';
  }
}, 10000);

// 60秒录音硬超时
this.voiceTimeoutId = setTimeout(() => {
  if (this.isRecording) {
    SpeechRecognizerManager.release();
    this.isRecording = false;
    this.micStarted = false;
  }
}, 60000);
```
